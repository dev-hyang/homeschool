# homeschool

家庭学堂 · 以信仰为中心的在家教育规划与记录。小月亮（baby-log）的姊妹应用：小月亮回答"刚才发生了什么"，家庭学堂回答"接下来做什么、做到哪了"。

纯静态网页，无构建步骤，托管在 GitHub Pages：`https://dev-hyang.github.io/homeschool/`。

## 姊妹应用

小月亮（`baby-log`）、家庭学堂（本仓库）、爱家小助手（`home-pantry`）三个站点同一个账号同一个家庭。站点列表在 `js/core/config.js` 的 `SISTER_APPS`；右上角两枚小标签 ‹ 上一个 / 下一个 › 环绕切换（和小月亮同一布局，连接状态在其下方），底部“我的”页和设置页里也有链接。

底部页签：今天 / 课程 / 资源 / 日历 / 我的。课程、资源、日历都是“入口页 + 子页”：入口页只放几行带摘要的入口（`me.js` 的 `mrow`），子页顶上有“‹ 所属页”返回（`views.js` 的 `PARENT` / `VIEWS`）。课程 → 单元与课时（单元卡默认折叠，只显示下一节）/ 年度范围 / 学习目标；资源 → 日常点子 / 资源库；日历 → 月历留在首屏，周例行是子页（默认只看今天这一天，七个星期片带条数可直接跳，‹ › 翻前后一天，“整周”铺开）。今天页不变。报告、法规、设置、介绍、打印（今日页 / 本周 / 本月）、姊妹应用都收在“我的”（`js/me.js`），宽窄屏一样，不折叠；报告和法规打开后顶上有“‹ 我的”返回。右上角只剩连接状态。

## 与小月亮的关系

- 同一个 Supabase 项目、同一个账号、同一个家庭、同一份孩子列表。两个站点都在 `dev-hyang.github.io` 下，登录会话通过浏览器自动共享。
- 创建家庭的人是家主（`family_members.role = 'owner'`，迁移 009）。家主在设置里可以重置邀请码、改任何成员的称呼（迁移 010 的 `set_member_name`）、把家人设为家主 / 转回成员、移出误加入的人；每个人也可以改自己的称呼。两个站点的设置页都能做，走同一组数据库函数。
- 孩子的名字和生日在小月亮里维护；这里只读。数据库里孩子来自 `children` 表（迁移 002），表还没建时回退到 `families.settings` 的 JSON。
- 数据库脚本（基线 `schema.sql` 加编号迁移）放在 baby-log 本地检出的 `supabase/` 目录，不进 git。本仓库以后新增的表也写成那里的迁移文件，在 Supabase SQL Editor 里手动执行。
- 在线优先：直接读写 Supabase，不做离线队列；本机只存"当前看哪个孩子"和主题。

## 定制流程（`js/flows.js`、`js/data/flows.js`）

资源页第一行，是一个层级：定制流程 → 睡前安然 / 冲突管理 / 以后补充的流程（`data/flows.js` 的 `FLOWS` 里加一项就出现在列表里）。

**冲突管理**：害怕、怕生、不愿分享、抢东西、打人、咬人、发脾气七种状况。每种按孩子现在的年龄段（2 岁前 / 2–3 / 3–5 / 5 岁起，沿用 `stageOf`）解释为什么，再给怎么做、怎么说、不要、经文、什么时候找专业人员；其他年龄段折叠着可看。依据儿童发展的一般共识，只作参考，不是诊断。

**记录怎么回填**（两个方向）：
- 家庭学堂 → 小月亮（自动）：在冲突管理里「记一笔」时，给每个参加的孩子往小月亮 `entries` 写一条 `behavior`（情绪行为：kind 按状况映射为害怕 / 打人咬人 / 发脾气，trigger 是状况名加起因，how 是怎么处理的，minutes 是持续分钟，note 带「来自家庭学堂 · 冲突管理」）。id 固定为 `hscf-<记录 id>-<孩子 id>`，所以改这笔会更新它，删这笔会把它标成已删，去掉的孩子那条也删，不会重复。页面上有开关（`bedtime.mirrorConflict`，默认开）。离线记的先排队，联网补传时一起写。
- 小月亮 → 家庭学堂（只读）：页面读小月亮近 61 天的 `behavior` 和 `social` 记录（RLS 决定看得到哪些），按孩子和状况映射统计近 30 天次数、与上个 30 天对比、平均持续、家里记过的处理办法；「分享合作」是好的记录，单独当亮点显示。读到的不会写回，也不复制。
- 补记：日期选过去的，小月亮那条落在那天中午。
- 记录存在 `hs_bedtime_events`（和睡前的状况记录同一张表，`situation` 以 `cf-` 开头区分，不另建表，无需新迁移）。

## 睡前安然（`js/bedtime.js`、`js/bedtime-play.js`、`js/data/bedtime.js`）

以诗篇 4:8 为中心的睡前敬拜流程，解决的是「孩子不好好睡、管教后又自责」：安抚多过刑罚，不等于不管教。入口在今天页最下方的卡片和「我的」。

- **流程**：五步模板（收拾转换 3 分 → 拥抱与敬拜 4 → 读诗篇 4:8 3 → 修复关系与祷告 5 → 音乐与安睡 5）和三步起步版（约 8 分钟）。每步可改名、改分钟、选歌（指定一首或按「被爱 / 神的话 / 休息」标签挑）、选显示哪段文字、跳过。合计超过上限（默认 30 分钟）标红提醒，不拦。
- **播放页**：整页深色、字大、只有「下一步」；不显示封面和歌词（父母要跟唱才点开）。每步一条细进度条 + 「约 n 分钟」，到时震一下、进度条变色，不响铃、不自动跳步；只有最后一步（循环）到时音乐 10 秒淡出，进入「今晚完成」。Media Session 让锁屏后继续放、锁屏上能暂停 / 下一步。「遇到状况」面板里有原则提醒、每种状况的做法和话，可以当场「记一笔」。
- **歌单**：自家的 MP3 / M4A 传到共用 Supabase 项目的私有 `media` 桶（迁移 019，单首 20 MB，家庭成员读写）；每台设备第一次播时下载并存进 IndexedDB，之后离线也能放。歌词可手填或「让 AI 补词」（用咩咩咩里的 key，标「AI 补的词」直到核对）。
- **带领词**：内置「家庭通用版」（开场、读经引导、祷告词、结束的话）。新建版本后随意改、可多版（幼儿版 / 学龄版 / 英文版），播放前选用哪版，每版可恢复成模板。
- **睡前经文**：十二段推荐（各带一句给父母的引导、一句问孩子的）+ 自家加的；诗篇 4:8 每晚先读（可关），再选一段今晚的。正文按设置里的抓取译本取，存本机。
- **状况与应对**：八种常见状况模板（不肯睡反复下床、打人抢玩具、说自己是坏孩子、父母发脾气、拖延、怕黑、兄弟姐妹打闹、涉及安全的严重事）各有推荐做法、可以这样说、不要、经文提醒，可改可加。每次发生记一笔（谁、怎么处理、几分钟、结果、值得继续用）；卡上显示近 30 天次数与上个 30 天的对比、平静下来比例、平均分钟，以及标了「值得继续」的做法。顶上是核心原则和箴言 13:24、以弗所书 6:4。
- **记录**：每晚一条（孩子、谁带、版本、经文、歌、计划 / 实际分钟、备注），进日历（金色点）和报告（「睡前安然 n 晚」）；可补记。开着「回写小月亮」时给每个参加的孩子写一条「信仰 · 家庭敬拜」记录（小月亮信仰模块打开才看得到），睡眠记录旁就能对照。
- **离线**：配置和歌单在本机留一份，没连上云端也能开播放页；完成记录和状况记录先排队，联网后自动补传。
- 配置（步骤、版本、经文清单、状况模板、上限、开关）在 `hs_family.settings.bedtime`；表和桶在 baby-log 本地 `supabase/migrations/019_bedtime.sql`。

## 云盘备份

> 详细的设置步骤（Google Drive 的 Client ID / API Key、Dropbox 的 App key 和 Redirect URI、本地文件夹、数据库重建、排错）见 [docs/backup-and-sync.md](docs/backup-and-sync.md)。

「我的 → 备份与恢复」可以把家庭学堂的数据定时备份到 Google Drive / Dropbox（手机电脑都能用）、电脑上的云盘同步文件夹、共用 Supabase 项目的存储（baby-log 迁移 017）或直接下载。Google Drive / Dropbox 要在 `js/core/config.js` 填两个公开的客户端标识（不是密钥）：

- Google Drive：Google Cloud Console → APIs & Services → 启用 Google Drive API → OAuth 2.0 客户端（类型 Web 应用），「已获授权的 JavaScript 来源」填站点地址，Client ID 填到 `GOOGLE_CLIENT_ID`。权限只有 drive.file（只看得到这个应用自己建的文件）。
- Dropbox：Dropbox App Console → Create app → Scoped access，Access type 选 **App folder**，Permissions 勾 `files.content.write` / `files.content.read` / `account_info.read`，Redirect URIs 填站点地址（带结尾的 /），App key 填到 `DROPBOX_APP_KEY`。
- 备份放在卡片里填的路径下：Drive 默认「家庭学堂备份」（可多级，不存在就逐级建）；Dropbox 是应用文件夹里的子路径。令牌存本机 localStorage，「断开」会吊销并清掉。代码在 `js/cloud-drives.js`，四个应用共用同一份。
