# homeschool

家庭学堂 · 以信仰为中心的在家教育规划与记录。小月亮（baby-log）的姊妹应用：小月亮回答"刚才发生了什么"，家庭学堂回答"接下来做什么、做到哪了"。

纯静态网页，无构建步骤，托管在 GitHub Pages：`https://dev-hyang.github.io/homeschool/`。

## 姊妹应用

小月亮（`baby-log`）、家庭学堂（本仓库）、爱家小助手（`home-pantry`）三个站点同一个账号同一个家庭。站点列表在 `js/core/config.js` 的 `SISTER_APPS`；右上角两枚小标签 ‹ 上一个 / 下一个 › 环绕切换（和小月亮同一布局，连接状态在其下方），底部“我的”页和设置页里也有链接。

底部页签：今天 / 课程 / 资源 / 日历 / 我的。课程、资源、日历都是“入口页 + 子页”：入口页只放几行带摘要的入口（`me.js` 的 `mrow`），子页顶上有“‹ 所属页”返回（`views.js` 的 `PARENT` / `VIEWS`）。课程 → 单元与课时（单元卡默认折叠，只显示下一节）/ 年度范围 / 学习目标；资源 → 日常点子 / 资源库；日历 → 月历留在首屏，周例行是子页（默认只看今天这一天，七个星期片带条数可直接跳，‹ › 翻前后一天，“整周”铺开）。今天页不变。报告、法规、设置、介绍、打印（今日页 / 本周 / 本月）、姊妹应用都收在“我的”（`js/me.js`），宽窄屏一样，不折叠；报告和法规打开后顶上有“‹ 我的”返回。右上角只剩连接状态。

## 与小月亮的关系

- 同一个 Supabase 项目、同一个账号、同一个家庭、同一份孩子列表。两个站点都在 `dev-hyang.github.io` 下，登录会话通过浏览器自动共享。
- 创建家庭的人是家主（`family_members.role = 'owner'`，迁移 009）。家主在设置里可以重置邀请码、改任何成员的称呼（迁移 010 的 `set_member_name`）、把家人设为家主 / 转回成员、移出误加入的人；每个人也可以改自己的称呼。两个站点的设置页都能做，走同一组数据库函数。
- 孩子的名字和生日在小月亮里维护；这里只读。数据库里孩子来自 `children` 表（迁移 002），表还没建时回退到 `families.settings` 的 JSON。
- 数据库脚本（基线 `schema.sql` 加编号迁移）放在 baby-log 本地检出的 `supabase/` 目录，不进 git。本仓库以后新增的表也写成那里的迁移文件，在 Supabase SQL Editor 里手动执行。
- 在线优先：直接读写 Supabase，不做离线队列；本机只存"当前看哪个孩子"和主题。

## 文件结构

```
index.html        页面骨架
app.css           样式（与小月亮同一套组件，但浅蓝底、海军蓝墨色、衬线标题、深蓝渐变 hero，一眼能分清）
js/
  app.js          入口
  core/config.js  Supabase 地址与公开 key、版本号、小月亮地址
  core/util.js    DOM / 时间小工具
  core/state.js   状态 S、孩子与年龄、阶段
  core/auth.js    登录、家庭、成员、孩子读取、实时刷新
  hs.js           数据层：读经计划、每日敬拜、经文卡与背诵进度、周例行、每日任务（hs_* 表）
  today.js        今天页：今日敬拜 → 经文背诵 → 今日任务
  course.js       课程页：领域 → 单元 → 课时（信仰连接、关联经文），学习目标
  resources.js    资源页：按领域 / 语言 / 类型筛选
  routines.js     日历页：月历（敬拜、任务完成、休息日）+ 周例行
  reports.js      报告页：按月出勤、每科时长、敬拜、经文、课时、目标，CSV 导出
  law.js          法规页
  me.js           “我的”页：报告、法规、设置、介绍、打印、姊妹应用的入口
  about.js        介绍页（设计思路、每页用法、节奏怎么把握）
  print.js        打印：今日页（竖版）、本周（横版表）、本月（月历 + 周例行）。按下后整页变成那张纸（打印视图：返回 / 打印），打印完自动返回；手机浏览器只打顶层页面，所以不用 iframe 和新标签页
  views.js        渲染与登录 / 家庭 / 孩子 / 建表的引导
  sheet.js        通用表单、经文卡库、设置页
  events.js       事件分发
  data/subjects.js  七个领域
  data/plans.js     读经计划模板与导入解析
  data/seeds.js     起步经文卡、周例行模板
  data/law.js       各州法规摘要（默认伊利诺伊；密歇根、印第安纳、北卡、田纳西供参考）
  data/curriculum.js 分龄课程库：阶段 → 领域 → 单元链（标题、建议周数、课时）
```

## 阶段

| 阶段 | 内容 | 状态 |
|---|---|---|
| 0 | 地基：共享登录、家庭、孩子切换；children 表迁移 | 完成 |
| 1 | 每日敬拜、经文卡与间隔复习、周例行模板、今日任务、读经计划模板与导入、法规页 | 完成（迁移 003） |
| 2 | 七个领域的课程树、信仰连接、学前目标 | 完成（迁移 004） |
| 3 | 中英文资源库、月历与休息日、教会年历预留 | 完成（迁移 004） |
| 4 | 月度报告与 CSV 导出、回写小月亮活动记录 | 完成（设置里开关） |
| 5 | 学年与假期、单元预计周数与“按计划 / 快 / 慢”、Pre-K 年度范围表、报告页节奏板块、介绍页 | 完成（迁移 006） |
| 6 | 分龄课程库（2–3 岁、Pre-K 写全，K 以后骨架）、按领域“生成下一单元”、“粘贴教材目录”生成课时 | 完成（迁移 008） |
| 7 | 经文背诵改任务式清单：到期复习自动进今天页、按年龄封顶（幼儿 1+1 / 学前 1+2 / 学龄 2+3）、✓/↻ 无打叉、做过的留在原位可撤销、连续三次再练提示“先放一放”、再练退一档间隔；卡库筛选（进行中 / 今天 / 在学 / 会背 / 放一放 / 没开始）与按复习时间排序 | 完成（迁移 011） |
| 7.1 | 复习间隔加一档 180 天（3、7、30、90、180）；复习排队超过配额两倍或拖满一周时，今天页提示并给“今天多复习 3 节”（只放宽当天配额） | 完成 |
| 8 | 每天 8 点自动安排经文（在学为空时从卡库随机挑一节，卡库背完自动从成套经文抓下一批 5 节，“换一个”随机换；设置里可关）；打印今日页 / 本周 / 本月 | 完成 |

设计方案见家庭内部的 Claude 文档《Homeschool 设计方案》。

## 本地调试

ES Module 需要通过 http(s) 访问：

```
python -m http.server 8766
```

然后打开 `http://127.0.0.1:8766/`。本地调试时和小月亮不在同一个源，登录要单独做一次。
